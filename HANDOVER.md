# HANDOVER: livestream-proto + VTuber mode

## Goal
Headless livestream (Xvfb + Chromium + FFmpeg). New this round: a **funny, artistic VTuber** whose face is
Python code, with babble voice (made from letters, no downloads), sound effects and karaoke subtitles.

## Current state (v2, 2.1.0): WORKING and tested
- `python3 -m unittest discover -s tests` -> 38 tests OK (original 20+ and new `tests/test_vtuber.py`).
- `python3 scripts/vtuber_preview.py` (headless Chromium) -> OK: mouth moves (o/small/smile seen), subtitles light up and hide.
  Screenshots are generated into `output/` by `python3 scripts/vtuber_preview.py` (not committed).
- Audio samples: `python3 -m vtuber --say "Hello" --emotion happy --out output/hello.wav`.
- Wired into `run.sh` (`VTUBER=1`, `VTUBER_NEWS=1`), `stop.sh`, `doctor.sh`, `.env.example`, Makefile, CI, README, CHANGELOG.

## NOT verified (could not be tested in the build sandbox)
- A real stream / `./run.sh --dry-run` (no Xvfb, PulseAudio or network there). The voice reaches the stream through
  Chromium -> PulseAudio `vsink` -> FFmpeg; confirm by listening to `logs/dry-run.mkv` after `./run.sh --dry-run --minutes 1` with `VTUBER=1`.
- `ruff` and `shellcheck` (not installed there). Bash syntax (`bash -n`) and JSON/YAML validity were checked.

## Decisions
- Kept the original flat project layout so `run.sh`, Docker and CI keep working. New code lives in `vtuber/` (acts as `src/`),
  user sounds in `assets/sounds/`, generated previews in `output/`, backups kept outside the repo.
- Face = Python-generated SVG (`vtuber/face.py`); the page only flips two attributes (`data-emo`, `data-mouth`) and CSS inside the SVG does the rest.
- Voice = pure-stdlib synthesis (`vtuber/voice.py`). No online audio is downloaded: the build sandbox had no network, and
  licensing is the user's call. Users drop their own WAVs in `assets/sounds/` and use `[name]` tags.
- Director -> page contract: `web/vtuber/now.json` + `web/vtuber/audio/line_N.wav` (polled every 400 ms; stale lines are not replayed).
- Lip-sync follows `audio.currentTime` when playing, else a wall clock from the moment the line started.
- `face.py` is exempt from ruff E501 (long SVG strings), set in `pyproject.toml`.
- `web/vtuber/face.svg` and `emotions.json` are committed (generated by `python3 -m vtuber --build`; a test checks they are current).

## Known issues (found in review)
- `scripts/vtuber_preview.py` is flaky: it needs 3 distinct mouth shapes in a short sampling window (passes ~2 of 3 runs), and it hard-codes line id 1, so a stale `web/vtuber/now.json` makes it fail. Delete `web/vtuber/now.json` before re-running, or use a clock-based id.
- `start.sh` does not offer VTuber mode; set `VTUBER=1` in `.env` by hand.
- README still contains `YOUR_USER` placeholders (README.md, docs/index.html).
- Not yet run for real: `./run.sh --dry-run` with VTUBER=1, `ruff`, `shellcheck`.
