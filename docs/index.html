Go live from any server.
No OBS. No monitor. No GPU.

A virtual screen, a browser and FFmpeg turn a web page into a 24/7 stream for Twitch, YouTube, Kick or any RTMP server.

Quick startBuild your config

This is the real overlay running in your browser with sample data.

Everything you need to stay on air

Standard library Python and a few shell scripts. Nothing to build.

🧩 Plug-in data sources

Hacker News, RSS/Atom, Reddit, GitHub, crypto prices, weather, static text, or any file another program writes.

🎞 Scene rotation + ticker

Lists, stat cards and big-text slides rotate on a timer, with a scrolling news ticker and progress bar.

📱 Live control panel

Show a banner, pin a scene or switch the theme from your phone. No restart, no dropped stream.

🔁 Self-healing

Reconnects with back-off when the connection drops, restarts a crashed browser, keeps last-good data when a feed fails.

🎨 4 themes, any resolution

Midnight, Daylight, Neon, Terminal. The canvas scales cleanly to 720p, 1080p or vertical.

🔒 Safe by default

Stream key masked in logs, .env git-ignored, control API bound to localhost and token-protected.

🩺 Doctor + dry-run

./doctor.sh checks your setup; ./run.sh --dry-run records a test file with no key needed.

🐳 Docker ready

One image, one docker compose up -d for VPS deployments. Published to GHCR by CI.

Quick start

Ubuntu, Debian or Google Cloud Shell.

  1. Get it
    git clone https://github.com/NotNahid/livestream && cd livestream
  2. Test without a key
    ./start.sh        # installs everything, choose option 6 "Just test"
  3. Go live — copy the files from the builder below (or run ./start.sh and answer the questions), then:
    ./doctor.sh && ./run.sh
  4. Steer it from http://127.0.0.1:8080/control.html
