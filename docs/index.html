    01

    Get it

    git clone https://github.com/NotNahid/livestream && cd livestream
    02

    Test without a key

    Installs everything. Choose option 6, “Just test”.

    ./start.sh
    03

    Go live

    Copy the files from the builder below, or run ./start.sh and answer the questions. Then:

    ./doctor.sh && ./run.sh

    Open the control panel. From a remote box, tunnel the port first.

    http://127.0.0.1:8080/control.html
