# Your own sound effects

Drop 16-bit PCM `.wav` files here (any sample rate, mono or stereo, up to 30 seconds).
The file name is the tag: `vine_boom.wav` -> write `[vine_boom]` in a line of `vtuber/lines.txt`.

- Names: lowercase letters, digits and `_`, up to 24 characters.
- A file here beats a built-in effect with the same name (`laugh.wav` replaces the synthetic laugh).
- Her mouth opens and closes with the loudness of the sample.
- Only add sounds you have the rights to (CC0 / public domain / your own recordings).
